# Личный кабинет — прототип ассистента

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Откройте адрес, который выведет Vite в терминале. На стартовом экране можно выбрать один из двух вариантов:

- **В личном кабинете** — текущая реализация с iframe кабинета и кнопкой запуска ассистента.
- **Самостоятельный режим** — версия без фонового кабинета. Ассистент запускается автоматически после preloader-экрана с анимацией кнопки.

Для прямого запуска можно использовать query-параметр:

```text
/?mode=cabinet
/?mode=standalone
```

Переключиться между режимами можно кнопкой в правом верхнем углу. В Firefox вместо проблемного cross-origin iframe показывается локальный снимок кабинета, потому что браузер может блокировать удалённый iframe из-за cookies/tracking protection и показывать ошибку `expected expression, got '<'`.

## Сборка

```bash
npm run build
```
